# بىلىك قۇرالى

بىلىك قۇرالى تور بەتلەردىكى تېكىستنى ئوقۇشقا ۋە كۆرۈنۈشىنى تەڭشەشكە ياردەم بېرىدىغان Chrome كېڭەيتىلمىسى.

## ئىقتىدارلىرى

- تاللانغان تېكىستكە ئوڭ چېكىپ «بىلىك قۇرالى» نى تاللاش ئارقىلىق تېكىستنى فورماتلاش.
- خەت نۇسخىسى، خەت چوڭلۇقى ۋە قۇر ئارىلىقىنى ئۆزگەرتىش.
- تېكىستنىڭ يېزىش يۆنىلىشىنى ئوڭدىن سولغا ياكى سولدىن ئوڭغا تەڭشەش، تېكىستنى توغرىلاش.
- تېكىستنى توركۆرگۈنىڭ ئاۋازلىق ئوقۇش ئىقتىدارى بىلەن ئوقۇتۇش؛ ئاۋاز، تېزلىك ۋە ئالدىنقى/كېيىنكى بۆلەكنى تاللاش.
- كونترول تاختىسىنى كىچىكلىتىش، قايتا ئېچىش ياكى تاقاش.

## قاچىلاش

1. بۇ ئامبارنى چۈشۈرۈڭ ياكى كومپيۇتېرىڭىزغا كلونلاڭ.
2. Chrome دا `chrome://extensions` نى ئېچىڭ.
3. **Developer mode** نى قوزغىتىڭ.
4. **Load unpacked** نى چېكىپ، بۇ پروجېكتنىڭ ھۆججەت قىسقۇچىنى تاللاڭ.
5. تور بەتنى قايتا يۈكلەڭ.

Microsoft Edge دا `edge://extensions` بېتىدىن ئوخشاش باسقۇچلارنى ئىجرا قىلىشقا بولىدۇ.

## ئىشلىتىش

1. تور بەتتە فورماتلىماقچى ياكى ئوقۇتماقچى بولغان تېكىستنى تاللاڭ.
2. تاللانغان تېكىستنىڭ ئۈستىدە ئوڭ چېكىپ، **بىلىك قۇرالى** نى تاللاڭ.
3. ئېچىلغان تاختىدىن خەت تەڭشەكلىرىنى ئۆزگەرتىڭ ياكى ئاۋازلىق ئوقۇش كونتروللىرىنى ئىشلىتىڭ.

ئاۋاز تاللاشلىرىنىڭ ئىشلىشى توركۆرگۈ ۋە ئۈسكۈنىدە قاچىلانغان ياكى تەمىنلەنگەن ئاۋازلارغا باغلىق. بەزى بەتلەردە توركۆرگۈنىڭ بىخەتەرلىك چەكلىمىسى سەۋەبىدىن كېڭەيتىلمە ئىشلىمەسلىكى مۇمكىن.

## پروجېكت ھۆججەتلىرى

- `manifest.json` — كېڭەيتىلمە تەڭشىكى ۋە ئىجازەتلىرى.
- `background.js` — تاللانغان تېكىستنىڭ ئوڭ چېكىش تىزىملىكىنى باشقۇرىدۇ.
- `content.js` — تېكىست فورماتلاش ۋە ئاۋازلىق ئوقۇش تاختىسىنى قوشىدۇ.
- `styles.css` — كۆرۈنمە يۈزى ئۇسلۇبلىرى.
